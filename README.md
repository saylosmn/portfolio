# [NER] — Миний булан

Нэр, Counter-Strike тоглогч гэсэн танилцуулга, Steam, Instagram, Facebook гэсэн гурван холбоостой нэг нүүртэй, хөнгөн сайт.

## Өөрчлөх

`index.html`-ийн эхэнд байгаа `CONFIG` объектод `name`, `tagline`, `steam`, `instagram`, `facebook` утгуудыг засна. Нэр болон гурван холбоос л харагдана.

## Байршуулж нийтлэх

Энэ нь статик HTML сайт тул `index.html`-ийг GitHub Pages эсвэл өөр статик хостингт байршуулна. GitHub Pages-д репозиторын **Settings → Pages** хэсгээс `main` салбарын үндсэн хавтсыг сонгоно. Фонт нь интернетээс ачаалагдах тул сүлжээгүй үед системийн нөөц фонт харагдана.
