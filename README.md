# [NER] — Нэг шөнийн раунд

Монголын CS2 тоглогчийн scroll-д хөтлөгдсөн, нэг HTML файлтай танилцуулга. Эхлэл хэсгийн оптик радар scroll-тойгоо эргэж, элсэн манхан болон утаан шилжилт хэсэг бүрийн явцад дагаж хөдөлнө. Хулганын онилгоо, газрын зургийн тэмдэг, kill-feed холбоосууд интерактив.

## Тохиргоо

`index.html`-ийн эхэнд байгаа `CONFIG` объектыг өөрийн мэдээллээр шинэчилнэ:

- `name`, `tagline` — дэлгэцийн нэр, танилцуулга.
- `steam`, `instagram`, `facebook` — олон нийтэд харуулах холбоосууд.
- `about`, `hours`, `rank`, `map`, `weapon` — товч түүх, тоглолтын үзүүлэлтүүд.
- `links` — холбоосын нэр болон товчилсон тэмдэглэгээ.

## Хостлох

`index.html`-ийг GitHub Pages, Netlify зэрэг статик хостингт байршуулж болно. GitHub Pages ашиглахдаа репозиторын **Settings → Pages** хэсгээс `main` салбарын үндсэн хавтсыг сонгоно. Сайт нь Unbounded/Golos Text фонтууд болон GSAP, ScrollTrigger, Lenis хөдөлгөөний санг CDN-ээс ачаална; эдгээрийг ачаалж чадахгүй байсан ч CSS-д суурилсан хэсгийн урсгал хэвийн харагдана. Ленисийн 1.1.18 хувилбар CDNJS-д байхгүй тул pinned jsDelivr хаягийг ашигласан.
